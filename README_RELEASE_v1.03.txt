WCA 報名 Release 1.03

檔案說明：
1) wca_registration_v1.03_mac_arm64.zip
   - 適用：Apple Silicon Mac (M1/M2/M3)

2) wca_registration_v1.03_mac_amd64.zip
   - 適用：Intel Mac

3) wca_registration_v1.03_win_x64.zip
   - 適用：Windows 64-bit (x64)

使用方式：
1. 下載對應平台 zip 並解壓縮。
2. 執行檔案後，瀏覽器開啟：
   http://127.0.0.1:18080
3. 在操作頁填入：
   - 報名網址（Registration 頁結尾需為 /registration）
   - 報名時間
4. 在人員分頁填入每位參賽者資料後執行。

v1.03 更新：
- 新增送出前等待秒數欄位
- 可自訂最後送出前延遲，模擬使用者操作
- 不同人員可分別設不同秒數，流程看起來更自然
- 報名成功後不關閉頁面

注意事項：
- 請填入實際可用的活動報名網址。
- macOS 若出現安全性阻擋，請到「系統設定 > 隱私權與安全性」允許執行後再開啟。

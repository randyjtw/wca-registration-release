WCA 報名 Release 1.04

檔案說明：
1) wca_registration_v1.04_mac_arm64.zip
   - 適用：Apple Silicon Mac (M1/M2/M3)

2) wca_registration_v1.04_mac_amd64.zip
   - 適用：Intel Mac

3) wca_registration_v1.04_win_x64.zip
   - 適用：Windows 64-bit (x64)

使用方式：
1. 下載對應平台 zip 並解壓縮。
2. 執行檔案後，瀏覽器開啟：
   http://127.0.0.1:18080
3. 在設定頁填入：
   - 報名網址（Registration 頁結尾需為 /registration）
   - 報名時間
4. 在選手分頁填入每位參賽者資料後執行。

v1.04 更新：
- 新增「查詢近期可報名賽事」，可直接套用
- 新增 開始/停止 按鈕：執行中可直接停止，停止後可重新開始
- 設定頁 新增各 Tab 資料總覽（姓名、WCA ID、email、生日、延遲秒數）
- 選手 Tab 名稱優化：有填資料時顯示「姓名與 WCAID 串接」
- 預設第1個 Tab 延遲2秒、第2個4秒、第3個6秒，有不同需求可自行修改
- 常用資料下拉時，即時載入，同時新增「清空」按鈕
- 常用資料不再儲存延遲秒數（僅保留基本資料）

注意事項：
- 請填入實際可用的活動報名網址。
- macOS 若出現安全性阻擋，請到「系統設定 > 隱私權與安全性」允許執行後再開啟。

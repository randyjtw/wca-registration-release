## 下載檔案

- `wca_registration_v1.05_mac_arm64.zip`：Apple Silicon Mac（M1/M2/M3）
- `wca_registration_v1.05_mac_amd64.zip`：Intel Mac
- `wca_registration_v1.05_win_x64.zip`：Windows 64-bit（x64）
- `SHA256SUMS_v1.05.txt`：檔案校驗

## 使用方式

1. 下載對應平台 zip 並解壓縮。
2. 執行檔案後，瀏覽器開啟 `http://127.0.0.1:18080`。
3. 在設定頁填入：
   - 報名網址（Registration 頁結尾需為 `/registration`）
   - 報名時間
4. 在選手分頁填入每位參賽者資料後執行。

## v1.05 新增 / 調整

- 每位選手可選裝置類型
- 不同 Tab 獨立裝置，9個iPhone就用9個代號
- UI調整 顯示「裝置+代號」

## 注意事項

- 請填入實際可用的活動報名網址。
- macOS 若出現安全性阻擋，請到「系統設定 > 隱私權與安全性」允許執行後再開啟。

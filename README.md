WCA 報名 Release 1.00

這個資料夾只包含執行檔，不包含源碼。

檔案說明：
1) wca_registration_v1.00_mac_arm64
   - 適用：Apple Silicon Mac (M1/M2/M3)

2) wca_registration_v1.00_mac_amd64
   - 適用：Intel Mac

3) wca_registration_v1.00_win_x64.exe
   - 適用：Windows 64-bit (x64)

使用方式：
- 執行對應平台檔案後，開啟瀏覽器進入：
  http://127.0.0.1:18080

主要功能：
- 支援多人併發報名
- 報名時間窗控制：開始前 5 分鐘到開始後 5 分鐘
- 到達報名頁時自動保存 HTML 快照供後續分析

注意：
- 報名網址需為 registration 頁，且以 /registration 結尾。
- 請自行填入實際活動報名網址。
